# BullsEye — 수동 테스트 체크리스트

Win32 레이어(단축키, 클립보드, 키 입력 시뮬레이션)는 자동 테스트가 어려워 이 목록으로 확인한다.

## 진단 모드

```bash
BullsEye.exe --probe                 # 기본 단축키 (Ctrl+Alt+Space)
BullsEye.exe --probe "Ctrl+Alt+K"    # 단축키 지정
```

다른 창에서 텍스트를 선택하고 단축키를 누르면, 진단 창에 활성 창 · 언어 · 위치(캐럿/마우스) · 캡처 결과가 표시된다.

> **주의:** 선택 캡처 전에 편집 영역을 클릭해 키보드 포커스를 넣을 것.
> 탭 머리글 등을 클릭하면 선택이 화면에 남아 보여도 Ctrl+C가 편집기에 가지 않는다.

## M4 — Win32 레이어

| # | 항목 | 방법 | 기대 결과 | 메모장 (개발 PC) | MATLAB (학교 PC) |
|---|---|---|---|---|---|
| 1 | 단축키 등록 | 진단 모드 실행 | "단축키 등록: …" | ✅ | ☐ |
| 2 | 선점된 단축키 | 이미 쓰이는 조합으로 실행 | "다른 프로그램이 이미 사용 중" 오류 | ✅ (`Ctrl+Alt+Space`가 개발 PC에서 선점됨) | ☐ |
| 3 | 활성 창 정보 | 단축키 누름 | 프로세스명 · 제목 | ✅ `Notepad.exe` | ☐ `MATLAB.exe` |
| 4 | 언어 감지 | 저장된 `.m` 파일에서 누름 | `MATLAB` | ☐ | ☐ |
| 5 | 선택 캡처 | 여러 줄 선택 후 누름 | 줄 수 · 들여쓰기 · 줄바꿈 | ✅ 127 ms | ☐ |
| 6 | 선택 없음 | 선택 없이 누름 | "없음 → 생성 모드" | ☐ | ☐ |
| 7 | 캐럿 위치 | 단축키 누름 | "캐럿" 또는 "마우스 (캐럿 못 찾음)" | ✅ 캐럿 | ☐ (Java 에디터는 마우스 예상) |
| 8 | 클립보드 쓰기 | "클립보드 쓰기 테스트" → Ctrl+V | 붙여넣기 됨 | ✅ | ☐ |
| 9 | 클립보드 기록 제외 | 8 이후 Win+V | `BullsEye probe …`가 기록에 **없음** | ☐ | ☐ |
| 10 | 포커스 되돌리기 | "포커스 되돌리기 테스트" | 직전 창이 앞으로 | ✅ | ☐ |
| 11 | 종료 시 정리 | 8 이후 진단 창 닫기 → Ctrl+V | 아무것도 붙여넣어지지 않음 | ✅ | ☐ |
| 12 | 관리자 권한 앱 | 관리자 권한 메모장에서 누름 | 캡처 실패 (UIPI) — M5에서 안내 문구 | ☐ | ☐ |

## 이후 마일스톤에서 추가할 항목

- M5: 팝업 · 설정 창 · 트레이 전체 흐름, 한글 IME 입력
- M6: USB 제거 시 종료, 유휴 종료 + 알림, 중복 실행 차단
- M7: 공용 PC에서 `openrouter.ai` 접속, `%TEMP%`에 파일 생성 없음, 백신 차단 여부
