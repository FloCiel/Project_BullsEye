# BullsEye — 수동 테스트 체크리스트

Win32 레이어(단축키, 클립보드, 키 입력 시뮬레이션)는 자동 테스트가 어려워 이 목록으로 확인한다.

## 진단 모드

```bash
BullsEye.exe --probe                 # 기본 단축키 (Ctrl+Alt+K)
BullsEye.exe --probe "Ctrl+Shift+F12" # 단축키 지정
```

다른 창에서 텍스트를 선택하고 단축키를 누르면, 진단 창에 활성 창 · 언어 · 위치(캐럿/마우스) · 캡처 결과가 표시된다.

> **주의:** 선택 캡처 전에 편집 영역을 클릭해 키보드 포커스를 넣을 것.
> 탭 머리글 등을 클릭하면 선택이 화면에 남아 보여도 Ctrl+C가 편집기에 가지 않는다.

## M5 — 설정 · 팝업 · 트레이

키 없이 확인하려면 가짜 provider로 실행한다 (API 호출 없음):

```bash
BULLSEYE_MOCK=1 BullsEye.exe
```

| # | 항목 | 방법 | 기대 결과 | 개발 PC (mock) | 학교 PC |
|---|---|---|---|---|---|
| 1 | 첫 실행 | 설정 파일 없이 실행 | 키 · PIN · 모델 입력 창, 잠금 줄 없음 | ✅ | ☐ |
| 2 | 모델 추가 | 모델 칸에 ID 입력 후 Enter | 즐겨찾기에 추가 (저장되지 않음) | ✅ (버그 수정 후) | ☐ |
| 3 | 암호화 저장 | 저장하고 시작 | exe 옆 `BullsEye.dat`, 내용에 키 평문 없음 | ✅ | ☐ |
| 4 | 잠금 해제 | 다시 실행 → PIN → Enter | 키 마스킹 표시, 설정 복원 | ✅ | ☐ |
| 5 | 잠금 상태 초기화 | PIN 화면에서 "초기화…" | 버튼이 눌림, 확인 후 첫 실행 화면 | ☐ | ☐ |
| 6 | 팝업 열기 | 코드 선택 → 단축키 | 캐럿 아래 팝업, 입력란 포커스 | ✅ | ☐ |
| 7 | 결과 | 지시 → Enter | 스트리밍 → 들여쓰기 맞춤 → "✓ 복사됨" | ✅ | ☐ |
| 8 | 모델 순환 | Ctrl+Tab | 헤더 모델 바뀜 | ✅ | ☐ |
| 9 | **Esc 후 포커스** | 결과 후 Esc → 바로 Ctrl+V | **원래 창으로 돌아가 선택 영역이 교체됨** | ✅ (회귀: 이전엔 다른 창이 활성화됨) | ☐ |
| 10 | **줄 전체 선택** | Shift+End 또는 다음 줄 시작까지 선택 후 교체 | **다음 줄과 합쳐지지 않음** | ✅ (회귀: 이전엔 `…;end`로 붙음) | ☐ |
| 11 | 바깥 클릭 | 팝업이 뜬 상태에서 다른 창 클릭 | 팝업 닫힘, 클릭한 창이 그대로 활성 | ☐ | ☐ |
| 12 | 한글 지시 | 한글 IME로 지시 입력 | 정상 입력 · 전송 | ✅ | ☐ |
| 13 | 재생성 | 결과 후 빈 Enter | 같은 지시로 다시 생성 | ☐ | ☐ |
| 14 | 실제 API | mock 없이 실행 → 지시 | OpenRouter 응답, "생각 중… N초" 표시 | ☐ | ☐ |

> **자동화 주의:** 화면 제어 도구로 테스트할 때 실제 Esc 키를 보내지 말 것. Claude 앱이 Esc를 받아 작업이
> 중단된다. 팝업 창에만 `WM_KEYDOWN(VK_ESCAPE)`를 `PostMessage`로 보내 확인했다.

## M6 — 수명주기

| # | 항목 | 방법 | 기대 결과 | 개발 PC | 학교 PC |
|---|---|---|---|---|---|
| 1 | 중복 실행 | 실행 중에 exe를 한 번 더 실행 | 두 번째는 바로 끝나고 프로세스는 하나 | ✅ | ☐ |
| 2 | 두 번째 실행 → 설정 | 1과 같음 | 기존 앱의 설정 창이 앞으로 옴 | ☐ (화면 잠김으로 미확인) | ☐ |
| 3 | 드라이브 제거 (폴링) | `subst X: <dist>` → X:에서 실행 → `subst X: /d` | 약 2초 안에 종료 | ✅ 약 2초 | — |
| 4 | **실제 USB 제거** | USB에서 실행 → 트레이 상태에서 USB 뽑기 | 즉시 종료, 트레이 아이콘 사라짐, Ctrl+V 해도 결과 없음 | ☐ | ☐ |
| 5 | 유휴 알림 | 유휴 종료를 5분으로 설정 후 방치 | 2분 30초쯤 "곧 종료" 알림 한 번 | ☐ | ☐ |
| 6 | 유휴 종료 | 5 이후 계속 방치 | 5분에 종료 (히스토리 저장) | ☐ | ☐ |
| 7 | 유휴 연장 | 알림 후 단축키 누름 | 종료되지 않고 다시 5분 | ☐ | ☐ |
| 8 | 예상치 못한 오류 | (재현 수단 없음) | 오류 창 후 종료, Windows 오류 보고 창 없음 | ☐ | ☐ |

> USB는 BullsEye를 트레이에서 "종료"한 뒤 뽑는 것이 원칙이다. 실행 중에는 exe가 사용 중이라
> "안전하게 제거"가 거부될 수 있고, 그냥 뽑으면 위 4번처럼 즉시 종료된다.

## 간소화 모드 (창 없이)

메모장에 아래를 쓰고 **세 줄 모두** 선택한 뒤 `Ctrl+Alt+J`:

```matlab
% >> 벡터화해줘
for i = 1:n
    y(i) = x(i)^2;
end
```

## 에이전트 (Ctrl+Alt+L)

먼저 `BULLSEYE_MOCK=1`로 흐름을 확인한다 (mock은 목록 → 첫 .m 파일 읽기 → 둘째 줄에 `% BullsEye mock: 검토함` 추가 → 요약 순서로 도구를 부른다).
개발 PC에서는 `BullsEye.exe --agent-demo <폴더>`(Debug 빌드만)로 PIN 없이 창만 띄울 수 있다.
실제 모델은 복사본 폴더에서 시험한다.

|---|---|---|---|---|---|
| 1 | 폴더 감지 | MATLAB 편집기를 분리(Undock)해 `Editor - C:\...\rect.m` 제목인 창에서 단축키 | 그 파일의 폴더로 창이 열림 | ☐ | ☐ |
| 2 | 폴더 폴백 | 제목에 경로가 없는 창(도킹된 MATLAB 본창 등)에서 단축키 | 지난번 폴더, 없으면 폴더 선택 창 | ☐ | ☐ |

| 9 | 모두 적용 | `Alt+A` | 그 작업의 나머지 변경은 묻지 않고 적용 (다음 지시에서는 다시 물음) | ☐ | ☐ |

| 12 | 단축키 재입력 | 창이 열린 채로 단축키 | 같은 창이 앞으로 (새 창 없음) | ☐ | ☐ |
| 13 | ChatGPT / OpenRouter | 두 서비스에서 각각 4~6 | 도구 호출이 이어지고 오류 없음 (Claude + 추론은 특히 확인) | ☐ | ☐ |

| 18 | 선택 없이 | 아무것도 선택하지 않고 단축키 | 에이전트 창이 열림 (예전과 같음) | ☐ | ☐ |
